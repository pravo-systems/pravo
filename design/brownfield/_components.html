Colour means something

Colour carries meaning on this site, so use it only for that meaning. The five status pills are the shared vocabulary for a resource in the cloud.

  • seen pravo found it and wrote it down. Blue-violet: discovered.
  • claimed You want it managed. Not finished. Amber: in progress.
  • managed In the state and in CUE. Green: good.
  • ignored Left alone on purpose. Neutral grey.
  • gone Recorded once, no longer in the cloud. Red.

Windows: terminal, files, diffs

All code lives in a window. Write plain text inside pre and name the language in data-lang: the script colours it and adds a copy button. Escape < and &. Windows are dark in both themes on purpose.

Terminal

Use data-lang="term". Lines starting with $ are commands, lines starting with # are dim, and + , ~ , - colour a whole line. Inline: {g|ok} green, {a|..} amber, {r|..} red, {k|..} blue-violet, {d|..} dim. The copy button copies the commands only.

CUE and JSON files

Other languages: hcl, sh, html. Highlight lines with data-hl="2,4-6" and show line numbers with data-numbers. Add data-nocopy on the figure to drop the copy button.

Step list

A plain numbered list for a short procedure. Windows can sit inside a step.

  1. Look

    pravo asks the provider what exists. Nothing changes.

  2. Decide

    You mark each thing: claim it, ignore it, or leave it for later.

  3. Adopt

    pravo writes the CUE and records the match. Now it is managed.

Interactive stepper

Click a step, use Back and Next, press the arrow keys, or press Play. Inside the SVG: data-show="2-4" shows an element only in those steps, data-hide hides it, data-cls="1:node--soft 2:node--seen" swaps the class from that step on, and data-text="1:unknown 2:seen" swaps a label. The h4 of each step becomes the button. Add data-autoplay to start when it scrolls into view.

  1. Ask the provider

    pravo asks the provider: what do you have in this account? It only reads.

  2. Write down what came back

    Every answer becomes a record marked seen. Nothing is managed yet.

  3. You decide

    Claim the bucket you want. Ignore the one you do not. Leave the third for later.

  4. Adopt

    pravo writes the CUE and links it to the real bucket. It is managed now.

Decision card and pushback card

The decision card is a discussion tool. Give it an id and it gains a stance and a note box that stay in the reader's browser. Mark the recommended option with is-recommended. In trade-offs, li is a benefit, li.cost a cost, li.risk a risk.

Should a scan cover the whole account or only what you point at?

open

Sample question. A wide scan finds more but costs more calls and takes longer.

Scope first recommended

You name a region and resource types; pravo scans only those.

  • Fast and cheap
  • Easy to explain
  • You can miss things outside the scope

Scan everything

One command walks every region and every type that can be listed.

  • Finds the most
  • Slow and noisy
  • May hit rate limits

Recommendation. Start with scope first and offer a wide scan as an explicit flag.

Definition list

pravo found it in the cloud account and wrote it down. It does not manage it.

You said you want it managed. The import is not finished.
managed
It is in the state and in your CUE. pravo plans changes to it.
ignored
You decided pravo should leave it alone. pravo remembers.
gone
pravo recorded it earlier and the cloud no longer shows it.

Diagram helpers

Draw diagrams as inline SVG with class="dg". Nodes are g.node with a status variant; arrows are path.arrow; .flow makes dashes march; .flow-dot with animateMotion sends a dot along a path. Both stop for readers who prefer reduced motion. Never use an emoji or a symbol character in SVG text: the fonts have no glyphs for them. Always give the SVG a role="img" and an aria-label.
