Self-service

Self-service that stays code.

A platform team writes a pattern once, as a definition. Anyone with a checkout fills in its form in the viewer and gets the code of a new instance. One person prepares the plan with a reader key, and someone with a writer key applies it.

01 · The form

The definition is the form

The types, defaults, comments and constraints of the fields become the form. There is no second schema to keep in step.

 02 · The checks

Checked before it is pasted

The viewer loads the specification with the new code in memory and tries every policy in force. The plan judges it again.

 03 · The instances

Instances follow their template

An instance is worked out from its template, not copied. Change the template, and the next plan changes every instance.
