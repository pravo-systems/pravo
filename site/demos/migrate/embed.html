What stays

  • The providers The same OpenTofu providers, plugin protocol {{data facts.protocols}}.
  • The infrastructure The objects are read, not recreated.
  • Review before apply A saved plan is read, then applied.

What changes

  • The language CUE replaces HCL. pravo has no converter for HCL.
  • The state format The directory pravo.state replaces terraform.tfstate.
  • The commands pravo replaces tofu.
  • Not carried over Taint, deposed objects and the records of the built-in provider. See M10.
