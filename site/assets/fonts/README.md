# Fonts

Self-hosted, latin subset, woff2. All three families are licensed under the SIL Open Font License 1.1.

| File | Family | Use |
|---|---|---|
| `newsreader-400.woff2`, `newsreader-500.woff2`, `newsreader-500-italic.woff2` | Newsreader (Production Type) | Display headings, lede |
| `plex-sans-400.woff2`, `-500`, `-600`, `-400-italic` | IBM Plex Sans (IBM) | Body and interface |
| `plex-mono-400.woff2`, `-500`, `-600` | IBM Plex Mono (IBM) | Code, kickers, labels |

The files come from the Fontsource distribution of the upstream releases. The latin subset has no arrows, check marks or mathematical symbols; the stylesheet draws those as masks.
