Assumptions

A different architecture, not a copy.

pravo solves the same problems, sometimes in another way. Some features of the earlier tools exist to work around a design that pravo does not have, so do not expect every concept to map one to one.

No workspaces

A tag selects the environment

Set -t env=prod and let the state path follow the tag. There is no extra concept to learn.

Not in pravo No -target

Apply part of a reviewed plan

A plan reaches only what a change reaches, and apply --only applies a closed part of a plan that was reviewed whole.

Not in pravo CUE, not HCL

One language for specs and policies

CUE is a superset of JSON and a constraint language, not a programming language. Modules need no input and output wiring, and a conflict is an error before any provider starts.

Learn CUE Bounded reads

Drift is checked on a budget

A plan does not read what it cannot reach. pravo drift reads the records that are most overdue, up to a limit you set.
